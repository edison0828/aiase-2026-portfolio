# 生成式 AI 應用系統與工程：課程作品集

**林冠宇｜114 學年度第 2 學期｜授課教師：國立成功大學莊坤達教授**

這個倉庫整理我在「生成式 AI 應用系統與工程」（Generative AI Application Systems and Engineering）課程中完成的四份作業與期末專案。公開版整理於 **2026 年 10 月 7 日**，用來說明我的實作內容、設計思考與目前能驗證的結果。原始作業透過 GitHub Classroom 繳交；這裡保留作品的主要程式與文件，另補上方便閱讀和重現的小型範例。

我在這門課中最有興趣的是：如何讓生成式 AI 的輸出能被檢查，以及如何把資料整理成可持續更新的知識。期末專案讓我練習將模型輸出接上程式驗證；個人 RAG 則讓我把儲存系統的閱讀筆記變成可以查詢、追溯來源的資料庫。這些實作也讓我更具體地理解，模型能力需要配合資料流程、記憶管理與軟體工程，才能形成可用的系統。

## 執行與驗證

各作品目錄都有自己的執行方式與相依套件。可以先從不需要金鑰的離線範例開始；涉及模型 API 或語意嵌入的部分，需另行配置環境。

公開整理時補做的檢查、適用範圍與尚未重跑的項目，集中在 [驗證紀錄](docs/VERIFICATION.md)。新增範例與測試用來檢查這次公開版，並非原課程繳交時的評分紀錄。

## 課程來源與整理方式

課程內容與作業要求可參閱 [AIASE 2026 課程倉庫](https://github.com/ktchuang/TAICA_AIASE2026)。部分專案由課程提供骨架或工具，我在各目錄中說明沿用的部分與本人完成的內容。課程實作及本次整理過程曾使用生成式 AI 協助程式、測試與文件；這些輔助不作為效能或正確性的證據。

公開版移除了課程評分工作流程、原始自動評分回覆，以及完整第三方論文檔案。文獻保留來源連結與閱讀摘要；實際金鑰、執行時資料庫和模型快取不納入倉庫。更完整的來源與版本說明見 [PROVENANCE.md](docs/PROVENANCE.md)。
