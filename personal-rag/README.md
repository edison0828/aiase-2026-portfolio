# 儲存系統筆記 RAG

這個專案來自「生成式 AI 應用系統與工程」HW3。我以自己閱讀 SSD、FTL 與儲存系統時整理的筆記為主題，練習把資料整理、檢索與回答串成可更新的流程。重點是讓回答能回到來源段落，也能在新增、修改或移除筆記後更新索引。

公開版保留課程提交中的主要程式，另在 **2026-10-07 公開整理**時加入離線範例、測試與清楚的模式提示。這些整理工作與原作業成果分別記在 [來源與修改說明](PROVENANCE.md)。

## 可以看到什麼

- Markdown／文字抽取、依段落切分及重疊。
- 以 SQLite 保存片段、來源資訊及向量，再計算 cosine similarity。
- 依檔案 SHA-256 判斷哪些來源需要更新，處理來源刪除。
- 附來源檔名與段落編號的檢索輸出；可選擇串接生成模型。
- 由檢索內容產生整理文件的 `skill_builder.py`。

目前附 **33 份原作業文字來源（22 份個人主題筆記、10 份論文閱讀摘要及 1 份來源清單），另加 3 份公開整理新增的虛構示範筆記**。未附論文全文、全文抽取結果或模型權重。論文閱讀摘要是個人的初讀整理，不等於原論文全文或經核實的研究結論；官方文獻連結可見 [延伸閱讀](SOURCE_REFERENCES.md)。公開版的 36 份文字來源均納入預設索引，不能沿用原作業包含 PDF 時的 194 chunks 數字。

## 先跑不需要金鑰的離線展示

需要 Python 3.10 以上。在本目錄執行：

```bash
python -m pip install -r requirements.txt
python data_update.py --rebuild
python rag_query.py --query "ambercache evicting persistent copy" --top-k 1
python skill_builder.py
python -m unittest discover -s tests -v
```

這裡的「離線」指安裝依賴後的執行階段。預設不下載模型、不呼叫 API，也不需要建立 `.env`。輸出會明示 `Embedding backend: hashing` 與「未使用生成模型」，此示範查詢會取回 `demo_read_cache.md`；來源欄位可用來回到原文核對，不能只看輸出的片段就當作回答。

**Hashing 模式是可重現的字詞雜湊檢索，不是語意嵌入。** 它有碰撞與斷詞限制，中文連續字串尤其不適合拿來評估語意檢索。這三份英文示範使用刻意放入的查詢詞，只展示流程是否正常。在完整筆記集上，即使查詢詞出現在某份筆記，也可能因雜湊碰撞而把其他片段排在前面；本次離線檢查也觀察到這個限制。擷取式輸出只是列出片段，不表示已回答問題或核實內容。

生成的索引與整理文件位於 `artifacts/`；處理後文字位於 `data/processed/`。這些執行產物不納入版本控制。`skill_builder.py` 的離線輸出含固定模板與檢索片段，應視為待檢查草稿。

## 使用自己的資料或模型

將有權使用的 `.md`、`.txt` 放入 `data/raw/` 後，再執行 `python data_update.py`。PDF 抽取需額外安裝 PyMuPDF，公開版不附第三方 PDF。

如需選用原程式的語意嵌入或生成模型，先安裝 `requirements-optional.txt` 中對應依賴。這些選配路徑在本次整理中**未實測**，安裝範圍及模型相容性仍需依自己的環境確認。

- 語意嵌入：設定 `EMBEDDING_PROVIDER=sentence-transformers`，並指定 `EMBEDDING_MODEL`。首次使用可能下載模型。
- 生成模型：可複製 `.env.example` 為 `.env`，填入自己的 `RAG_API_KEY`、`RAG_BASE_URL`、`RAG_CHAT_MODEL`。端點應支援 OpenAI-compatible chat completions；未預設任何課程或付費服務。
- **更換嵌入方法、模型或切分參數後，請用 `--rebuild` 重建整個索引。** 目前程式不自動核對既存向量的模型版本；建索引與查詢必須使用一致設定。
- 選用語意模型失敗時，公開版會報錯，不會靜默改成雜湊向量。API 回答失敗時則明示改用擷取式輸出。

## 已驗證的範圍與限制

2026-10-07 在 Python 3.12 環境通過 3 項新增整合測試：離線索引與來源顯示、來源更新／刪除、無生成模型的整理文件輸出。測試在暫存副本執行，不寫入正式語料。詳見 [驗證紀錄](VERIFICATION.md)。

這是小型課程實作，尚無人工標註查詢集、回答品質評估或大規模效能結果。SQLite 查詢會載入所有向量，並非近似最近鄰索引。切分以段落為單位，單一過長段落可能超過設定字元數；來源標記也不保證生成模型的敘述正確。
