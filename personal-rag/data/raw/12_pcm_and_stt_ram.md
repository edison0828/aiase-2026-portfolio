# PCM and STT-RAM

作者：Edison Lin
類型：個人研究筆記
主題：PCM 與 STT-RAM 的系統研究關注點

PCM 常被討論為具持久性與低延遲潛力的介質，但其寫入成本、耐久度與熱效應會影響系統整合方式。研究者在設計 PCM-aware 系統時，通常需要重新思考寫入頻率、資料布局與耐久化粒度。

STT-RAM 則常被放在 cache 或 memory hierarchy 的脈絡下討論。它的潛在高速與非揮發性很有吸引力，但容量、成本與寫入能耗仍是重要限制。這意味著系統設計通常不會直接把它視為 DRAM 替代品，而是考慮如何放在多層快取或混合記憶體架構中。

兩者的共同點是，它們都要求軟體別再把底層介質視為均質資源，而是要根據耐久性、寫入代價與延遲特性做更細的 placement 決策。
