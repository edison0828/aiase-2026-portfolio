# RRAM and Skyrmion

作者：Edison Lin
類型：個人研究筆記
主題：前沿 NVM 技術與未來軟體介面

RRAM 經常被視為具有高整合潛力的非揮發性記憶體候選技術，但實際系統整合仍會受到製程穩定性、寫入一致性與長期可靠度影響。對軟體研究者來說，關鍵不是背規格，而是理解若這類介質成熟，資料結構與持久化路徑可能如何改變。

Skyrmion-based memory 更偏前瞻性研究。它的價值在於提供新的硬體能力假設，逼迫我們提前思考未來介面該如何設計。若未來介質同時具備新型密度、能耗或可移動資料表示方式，現有抽象不一定足夠。

因此這類文獻適合被視為 future computing paradigms 的一部分。即便短期內不會直接部署，它們仍能幫助研究者練習從硬體能力出發反推軟體設計機會。
