# 來源與公開版整理說明

## 版本來源

本倉庫由林冠宇提供的五份 GitHub Classroom 作業 ZIP 整理而成：HW1、HW2、HW3、HW4 與期末專案。ZIP 不包含 Git 歷史，因此本倉庫的提交日期代表公開整理日期，無法用來還原原作業逐次提交的時間。

課程為國立成功大學莊坤達教授於 114 學年度第 2 學期開設的「生成式 AI 應用系統與工程」。課程講義及作業入口：<https://github.com/ktchuang/TAICA_AIASE2026>。

## AI 輔助與結果呈現

原課程屬 AI 輔助工程實作，文件中可見使用 AI 工具協助需求、程式及除錯的紀錄。期末專案報告明列使用 Codex 輔助測試、報告草稿與除錯；本次作品集整理也使用 Codex 協助編修與驗證。作品展示著重可檢視的程式、設計與執行結果，不以自動評分回覆證明正式成績或研究效能。

HW4 原報告的混合檢索數字與自動評測回覆不一致，因此公開說明未採用尚無法確認的改善幅度。離線驗證也不代表模型 API、Hermes 或 Pi 完整整合已重現。
